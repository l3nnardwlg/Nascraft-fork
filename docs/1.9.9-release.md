# Nascraft 1.9.9

Nascraft 1.9.9 is a market stability and UX release focused on issue #22.

## In-game market

- Added item search to the main market menu with alias, identifier and material matching.
- Hardened in-game chart generation for empty or sparse price history.
- Added a current-price fallback so a chart can still render before enough historical samples exist.
- Prevented invalid NaN/Infinity chart statistics on short histories.
- Improved the market item editor input flow and validation.
- Added buy-enabled and sell-enabled controls directly to the item editor.
- Hardened category creation and category editing, including duplicate/invalid identifiers and safe persistence.
- Prevented deletion of categories that still contain market items.

## Web extension

- Added chart range controls for 1m, 5m, 30m, 1h, 12h, 1d, 7d and all history.
- Kept stepped chart rendering for sparse/discrete market price updates.
- Reworked the compact brand header so the Nascraft name sits below the logo instead of being squeezed beside it.
- Added Settings next to the logged-in player name.
- Added a Reduce Animations preference stored locally in the browser.
- Added a visible Coming Soon notice for Discord alerts and future integrations.
- Preserved trade duplicate-submit protection, request IDs, copy fallback and the Max trade helper.

## Compatibility

- Existing market data, categories and price history are preserved.
- The Gradle/project version is bumped to 1.9.9.
